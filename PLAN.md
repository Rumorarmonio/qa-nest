# План реализации

## Проект

QA Backend - учебный backend на NestJS + Prisma + PostgreSQL для сценария вопросов и ответов с JWT-аутентификацией, ролями USER/ADMIN, CRUD для questions/answers, сидерами, Swagger, тестовой инфраструктурой и планируемой админкой.

## Цель

Довести backend/API до устойчивого MVP: закрыть критичные вопросы авторизации и прав доступа, зафиксировать бизнес-инварианты на уровне сервиса и БД, покрыть важные сценарии тестами, затем подключить админку. После этого можно переходить к frontend-контрактам и самому frontend.

## Этапы

1. Стабилизировать API и модель данных: ownership rules для вопросов и ответов; правила удаления answers; constraint на единственный best answer в Postgres; тесты на auth, roles и бизнес-логику; при необходимости уточнение поведения ошибок и статусов.
2. Подключить админку: доступ только для ADMIN; ресурсы User, Question, Answer; скрытие чувствительных полей; базовые действия модерации и управления контентом; минимальный набор экранов без лишнего scope.
3. Расширять продукт после стабилизации backend: поиск и фильтрация вопросов, теги/категории, комментарии, лайки, уведомления, затем frontend-контракты и frontend-приложение.
